1. OVERVIEW & SYSTEM ARCHITECTURE
================================================================================
GetHotelStays.com is a modern, enterprise-grade travel and hotel booking 
platform engineered for speed, high-conversion user experience, automated 
hotel onboarding, dynamic pricing, and comprehensive partner/super-admin 
management.

The ecosystem consists of 5 tightly integrated components:
- Main Web Application : React 18 + Vite + TypeScript + TailwindCSS
- API Server           : Node.js + Express + Prisma ORM + MySQL
- Chrome Extension     : Manifest V3 Hotel Scraper Agent (MakeMyTrip / OTAs)
- Blog Engine          : High-Performance Pre-Rendered Static SEO/AEO/GEO Platform
- AI Assistant Sub-App : Dedicated AI Chatbot for Conversational Hotel Booking

- packageController.js     : Tour package management & JSON importer.
- adminController.js       : Platform statistics, user management, audit logging.
- aiChatController.js      : AI room search and conversational endpoints.

7. DATABASE SCHEMA & DATA MODELS (PRISMA + MYSQL)

- DailyRate: Id, roomId, date, price, availableCount.
- Package  : Id, title, duration, price, heroImage, itinerary, destinations.

================================================================================
1. Hardened CORS Whitelist:
   - Allows gethotelstays.com, ai.gethotelstays.com, localhost, and chrome-extension:// origins.
2. Anti-Hacker Middleware (security.js):
   - IP Blocker (blocked_ips.json dynamic lockout).
   - Bot Scanner (blocks malicious scrapers/bots).
   - Request Size Limiter (15MB payload cap).
   - Double-Submit Cookie CSRF Protection (with extension & public API bypass).
3. Input Sanitizer (sanitizeInput.js):
   - Prevents XSS, prototype pollution, and deep nesting payload attacks.
